# Project Skills

Task-specific procedures for AI agents working on Nova Store (`next.js-e-commerce-main`).

Read `ai/agents.md` to choose the relevant skill. Read only the skill needed for the current change.

## Available skills

- `customer-auth-account/SKILL.md` — NextAuth, user roles, account profile, and access control.
- `catalog-inventory-dashboard/SKILL.md` — product catalog, SKU stock, stock alerts, dashboard metrics, and admin operations.
- `orders-lifecycle/SKILL.md` — order history, ownership, cancellation, lifecycle transitions, and delivery snapshots.
- `ecommerce-domain/SKILL.md` — catalog, pricing, cart, inventory, checkout, orders, and domain boundaries.
- `payment-integrations/SKILL.md` — Mercado Pago, Stripe, PayPal, seller onboarding, commissions/split, refunds, and payment webhooks.
- `shipping-integrations/SKILL.md` — Zipnova, Shippo, local shipping options, labels, fulfillment, and tracking.
- `database-postgresql/SKILL.md` — PostgreSQL and the project's Prisma 7 adapter/migration workflow.
- `nextjs-feature/SKILL.md` — App Router, Route Handlers, Server Actions, server/client boundaries, and data fetching.
- `reactjs-feature/SKILL.md` — React components, local/global state, effects, and accessibility.
- `i18n/SKILL.md` — next-intl, locale routing, dictionaries, and localized copy.
- `forms-validation/SKILL.md` — React Hook Form, Zod resolvers/schemas, accessible errors, and server-side validation.
- `ui-styling/SKILL.md` — shared web UI, responsive design, and accessibility.
- `ui-styling/tailwind/SKILL.md` — Tailwind-specific conventions.
- `mobile-app/SKILL.md` — Expo/React Native screens, navigation, state, and native dependencies.
- `mobile-api-sync/SKILL.md` — API/CORS/auth contracts shared with the mobile app.
- `platform-integrations/SKILL.md` — Brevo, PostHog, Logtail, GraphQL Yoga, Telegram, and scheduled jobs.

Cross-cutting documents such as `ai/doc/security.md`, `ai/doc/testing.md`, and `ai/doc/validation.md` are selected by `ai/agents.md` when relevant.
