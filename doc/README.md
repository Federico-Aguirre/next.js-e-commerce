# Project Documentation

This directory contains reusable guidance for the template. Keep these documents framework- and project-aware: they should define durable conventions, not encode assumptions that only fit one application.

## Core documents

- `typescript.md` — type safety, imports, functions, and TypeScript conventions.
- `tailwindStyles.md` — Tailwind CSS, responsive styling, reusable UI, and accessibility.
- `react.md` — component boundaries, state, effects, composition, and accessibility.
- `nextjs.md` — App Router, server/client boundaries, validation, and performance.
- `testing.md` — choosing test levels, test quality, and validation checkpoints.
- `security.md` — input validation, secrets, authorization, and secure web behavior.
- `validation.md` — persistent validation checkpoints for the current project.

Read only the documents relevant to the change. Add another document when a recurring project concern is substantial enough to deserve its own durable rules.
