# Project Skills

This directory contains task-specific procedures for AI agents working on Nova Store (`next.js-e-commerce-main`).

Read only the skill relevant to your current task before making changes.

## Available Skills

- [`commerce-domain`](./commerce-domain/SKILL.md): Pure pricing, promotions, contracts, catalog domain models, and customer session verification.
- [`mobile-api-sync`](./mobile-api-sync/SKILL.md): Backend API routes, CORS compatibility, and synchronization with `ecommerce-mobile/`.
- [`nextjs-feature`](./nextjs-feature/SKILL.md): App Router pages, layouts, Server Actions, and data fetching boundaries.
- [`database-postgresql`](./database-postgresql/SKILL.md): Prisma ORM models, migrations, seeds, and database queries.
- [`security`](./security/SKILL.md): Secrets, validation boundaries, authentication, and authorization checks.
- [`testing`](./testing/SKILL.md): Unit/component tests with Vitest and E2E browser tests with Playwright.
- [`i18n`](./i18n/SKILL.md): Localization dictionaries (`en.json`, `es.json`), routing, and `next-intl` formatting.
- [`ui-styling`](./ui-styling/SKILL.md): Tailwind CSS v4, shared Radix/Shadcn UI components, responsive layout, and accessibility.
